# 一心问道 · 个人主页

一套自包含的静态个人网站，包含首页和三篇随笔。可将本目录的全部文件复制到个人 GitHub Pages 仓库根目录发布，无需构建工具。

## 公开资料

仅公开笔名“一心问道”、华南理工大学博士在读、研究方向“智能生物解析”、用户提供的邮箱，以及已授权的公众号和小说创作。没有展示真实姓名、年龄、导师、详细学历或住址。

## 内容与资源

- `index.html`：首页介绍、研究兴趣、小说、公众号、创作方向、随笔、关于与联系。
- `notes/`：三篇原创短文。更新文字后，应同步更新字体子集，或使用具有完整覆盖的中文字体。
- `style.css` / `site.js`：响应式样式、移动菜单、研究兴趣选项卡和复制交互。
- `assets/dog-portrait.png`：使用内置图像生成工具制作的网站头像，生成提示为“暖白纸面上的精细钢笔线描小狗，安静坐着、微微歪头、长耳朵、文学杂志插画感，无文字、无水印”。
- `assets/journal-song.woff2`：Noto Serif CJK SC 的内容字形子集，许可见 `assets/OFL.txt`。
- 小说阅读及 PDF 链接指向现有《在我们理解大脑之前》网站。

## 校验范围

检查本地链接、锚点、重复 ID、选项卡关联、公开身份范围及中文字体覆盖。使用 DOM 测试验证菜单、键盘切换与剪贴板成功/失败反馈；版面采用桌面与窄屏静态渲染复核。本次可用的站点预览技能未提供浏览器控制能力，因此未进行真实浏览器端验收。
