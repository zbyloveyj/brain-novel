当前 `docs/` 是经过完整排版、测试和配置的**静态网站发布目录**。请在 `Settings → Pages → Build and deployment` 选择 `Deploy from a branch`，分支 `main`，目录 `/docs`，不要切换到其他产物以免丢失网页交互功能。根目录中的 `.qmd` 是便于编辑的 Quarto 书稿源文件，暂不包含静态阅读器的全部交互。
